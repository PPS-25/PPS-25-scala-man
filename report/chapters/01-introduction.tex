\chapter{Introduction}

\textbf{Scala-Man} is an arcade game inspired by the classic Pac-Man.

The player moves inside a maze filled with collectible items and enemies. The game combines the following
core mechanics:

\begin{itemize}
  \item \textbf{Collection and survival}: the player clears the maze while avoiding enemies; being caught costs a
  life, and the game ends once no life remains.
  \item \textbf{Enemy strategies}: the \textbf{Hunter} follows the player, the \textbf{Anticipator} tries to cut off
  their path, and the \textbf{Patroller} follows a set path.
  \item \textbf{Mobility and bonuses}: teleports instantly carry whoever steps on them to their paired endpoint,
  while special items grant temporary invulnerability or slow enemies down.
\end{itemize}

Three \textbf{game modes} offer distinct objectives and ranking criteria:

\begin{itemize}
  \item \textbf{Classic}: collect every standard item; bonuses, defeated enemies, and remaining lives add points.
  \item \textbf{Timed}: complete the same objective as quickly as possible.
  \item \textbf{Survival}: survive increasingly fast enemies; the score grows with each difficulty increase.
\end{itemize}

Players can provide their own maps as plain-text files using the documented ASCII format. Each map is
\textbf{validated before play} to guarantee that it is well formed and that all collectibles are reachable.

The game also supports the following player-facing features:

\begin{itemize}
  \item a \textbf{leaderboard} for each map--mode combination, ordered by descending score;
  \item \textbf{saving and loading}, so a paused game can be resumed later from the start menu.
\end{itemize}

Beyond being playable, the project is designed around three quality goals:

\begin{itemize}
  \item \textbf{Extensible enemy behaviour}, through new strategies;
  \item \textbf{Extensible game modes}, without changing the application core;
  \item \textbf{Independent model testing}, without a graphical interface.
\end{itemize}
